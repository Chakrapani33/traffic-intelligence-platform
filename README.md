# 🚦 RT-TIARP

**Real-Time Traffic Intelligence & Accident Risk Prediction Platform**

A web application that monitors traffic and predicts accident risk in real time.

### ✨ Features

* 🚦 Real-time traffic monitoring
* ⚠️ Accident risk prediction
* 🗺️ Live map with risk locations
* 🌤️ Weather information
* 🔔 SMS alerts
* 📊 Traffic analytics & reports

### 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Leaflet
**Backend:** Python, FastAPI, WebSocket
**Database:** PostgreSQL, MongoDB, Redis
**Tools:** Docker, Twilio, OpenStreetMap

### 🚀 Run the Project

```bash
# Backend
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173** in your browser.
